# Sample videos

- `roundabout-input.mp4` — example **input** video: aerial footage of a roundabout with
  everyday traffic. Use it to try upload, captioning, search/Q&A, summarization, and tracking.
- `roundabout-tracked.mp4` — example **output**: the same clip after the blueprint's object detection and tracking pass (YOLO11 + ByteTrack), with bounding boxes and persistent IDs drawn on a tracking-overlay copy. Generated by this blueprint from the input above.
- `intersection2.mp4` — example **input** video: a render, not real footage: a small city junction seen from a fixed camera on a mast, 20 seconds long, with five cars and one crash at t = 14.0 s.
- `intersection2-tracked.mp4` — example **output**: the same clip after the blueprint's object detection and tracking pass (YOLO11 + ByteTrack), with bounding boxes and persistent IDs drawn on a tracking-overlay copy. Generated by this blueprint from the input above.
